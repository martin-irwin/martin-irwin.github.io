## Prompt: the kuroshi deck, briefly

- What the VAIO P setup is: antiX + i3, Night City palette, urxvt, conky DIAGNOSTICS panel, `jack` (Super+G) to SSH into the tailnet, tmux "deck", themed login and console.
- Design rule it was built on: cost nearly nothing on an Atom (no compositor, no transparency, one resident terminal).
- Prompt: why a theme matters on a machine whose whole job is a terminal.

## Prompt: a smaller screen is not a smaller version

Technical flow:
- VAIO P: 1600×768 on ~8" ≈ 222 ppi. VAIO UX: 1024×600 on ~4.5" ≈ 264 ppi.
- So the UX is *denser*, not just smaller. Shrinking everything to fit would make text physically smaller than on the P. Keep the pixel sizes (terminal stays 14pt) and show less instead.
- Prompt: the "aha" about density vs resolution.

## Prompt: one theme, host profiles instead of a fork

Technical flow:
- `hosts/<name>/` per machine: `profile.conf` (`NAME`, `SIZE`, `MODEL`, `SPEC`), `files/` (an overlay: art, conky, login theme), `apply.sh` (small idempotent `sed` edits).
- `./install.sh --profile ux` lays the overlay over the bundle, runs the hook, and remembers the choice. The plain bundle is still the VAIO P, untouched.
- Things that needed no profile at all because they already read `hostname`: the prompt, the i3 bar badge, and now tmux:
  ```
  run-shell 'tmux set -g @deckhost "$(hostname | tr a-z A-Z)"'
  set -g status-right "… NET//#{@deckhost} …"
  ```

## Prompt: generated art, parameterised

Technical flow:
- All art is generated by one Pillow script (`tools/gen-art.py`): wallpaper with a framed conky panel, lock screen, login background + panel, console banner, console palette.
- New options: `--size WxH --name --model --spec`; under 1300 px wide it switches to a **compact** layout: key hints in three rows, headline fitted to the free width and capped at 150 px, lock text kept above i3lock's ring, login panel moved to 70% so it fits 1024 px.
- Regression check: with no options it redraws the VAIO P art **pixel-identically** (compared image by image), so the original machine can't be broken by the port.
- `tools/build-profile ux` draws a profile's art in both palettes (coral and Netrunner).
- A bug a 2-letter name caught: "UX" fitted the width at full size, grew too tall, and pushed the key hints into the telemetry block. Hence the height cap.

## Prompt: the panel that didn't fit

Technical flow:
- The DIAGNOSTICS panel is ~650 px of content; the UX has ~536 px under the bar.
- UX profile drops uptime, load, swap and the traffic graphs, and caps the NETRUNNERS host list (`jack --conky | head -n 5`; conky's `execpi` runs through a shell, so pipes work).
- Hardware differences found on the real machine: the battery is `BAT1` (not `BAT0`), the CPU sensor path matched, Wi-Fi is still `wlan0`.
